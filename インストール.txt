仮想環境を作る
$ python3 -m venv V_ollama
仮想環境に入る
$ source V_ollama/bin/activate

仮想環境から出る
$ deactivate


仮想環境でインストール

ollamaインストール
$ pip install ollama

flaskインストール
$ python3 -m pip install flask


プログラムをダウンロード

git clone https://github.com/momorara/LLM_chat

ディレクトリ移動
cd LLM_chat

ターミナルでプログラムを起動
・CLI版 python chat_cli.py
・Web版 python app.py
　　　　　その後、webプラウザで　http://<ipアドレス>:8000
